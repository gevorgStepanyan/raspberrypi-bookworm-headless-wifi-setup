# WiFi Configuration File
# Format: SSID,password,priority[,identity,ca_cert,altsubject]
# 
# For WPA-PSK (Normal WiFi):
# SSID,password,priority
#
# For WPA-EAP (enterprise):
# SSID,password,priority,identity,ca_cert,pass_file
#
# Higher priority number = higher priority (tried first)

# WiFi Networks
# Primary network (highest priority)
# NetWorkName,NetworkPassword,3

# Backup network (lowest priority)
# Net Work Name 2,password2,1

# Example Advanced WiFi
# SSID,PASSWORD,priority,email_identity,path_to_cert,altsubject
